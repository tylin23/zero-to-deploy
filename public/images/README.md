# 場景圖放這裡

第 1 關「前端 vs 後端」那一步會用到一張**市民服務中心大廳**的圖，
圖上會疊 6 個互動標記（入口大門、抽號碼機、手機、等候區、櫃台、後方檔案櫃）。

## 怎麼放

把圖片存成這個檔名放進這個資料夾：

```
public/images/service-center.jpg
```

- 檔名要**完全一致**（全小寫、用 `-` 不要用空白）——伺服器分大小寫。
- 建議尺寸 **16:9**（例如 1656×929 或 1920×1080），元件會以 16:9 裁切。
- 用 `.jpg`；如果要換成 `.webp` 或 `.png`，
  請一併改 `src/components/SceneMap.jsx` 最上面的 `SRC`。

## 沒放會怎樣

整張圖連同標記都不會顯示，該步驟仍然有完整的文字卡片可以上課，
不會出現破圖或空白區塊。

## 標記位置要微調的話

座標寫在 `src/components/SceneMap.jsx` 的 `SPOTS`，
`x` / `y` 是「箭頭指到的那一點」在圖上的百分比（左上角為 0,0）。
