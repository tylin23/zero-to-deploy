# 場景圖放這裡

第 1 關「前端 vs 後端」那一步會用到一張**市民服務中心大廳**的圖，
圖上會疊 5 個互動標記（入口大門、抽號碼機、一般櫃台、敬老／愛心櫃台、後方檔案櫃）。

## 怎麼放

把圖片存成這個檔名放進這個資料夾：

```
public/images/service-center.jpg
```

- 檔名要**完全一致**（全小寫、用 `-` 不要用空白）——伺服器分大小寫。
- 建議尺寸 **16:9**（例如 1656×929 或 1920×1080），元件會以 16:9 裁切。
- 用 `.jpg`；如果要換成 `.webp` 或 `.png`，
  請一併改 `src/components/SceneMap.jsx` 最上面的 `SRC`。

## 沒放會怎樣

整張圖連同標記都不會顯示，該步驟仍然有完整的文字卡片可以上課，
不會出現破圖或空白區塊。

## 標記位置要微調的話

座標寫在 `src/components/SceneMap.jsx` 的 `SPOTS`，
`x` / `y` 是「箭頭指到的那一點」在圖上的百分比（左上角為 0,0）。

# AI 工具的介面截圖（第 1 關）

第 1 關「上線的方法有哪些？」的三張 AI 工具卡，展開後會顯示「入口在哪」。
文字路徑一定看得到；**截圖是加分的輔助**，放了更好，沒放也不影響上課。

## 怎麼放

把三張截圖存成這些檔名放進這個資料夾（檔名要完全一致、全小寫）：

```
public/images/ai-claude.png     ← Claude 左側選單，框出 Artifacts
public/images/ai-gemini.png     ← Gemini 輸入框的「＋」選單，反白 Canvas
public/images/ai-chatgpt.png    ← ChatGPT／Codex 左側選單，框出「網站」
```

- 盡量只截**選單那一塊**，不要整個視窗——卡片裡最高顯示 400px（手機 220px），
  圖上空白越多，選單文字就被縮得越小。
- 截圖前先確認畫面上**沒有你的帳號名稱、email、對話內容**——
  這個網站是完全公開的。
- 用 `.png`（介面截圖用 PNG 比較清楚）。要改成別的副檔名，
  請一併改 `src/levels/LandscapeLevel.jsx` 裡 `ToolShot` 的 `src`。

## 沒放會怎樣

那一格圖就不顯示，卡片上仍然有「左側選單 › Artifacts」這種文字路徑，
不會出現破圖或空白區塊。

## 介面改版了怎麼辦

三家的選單位置變動很快。文字路徑寫在
`src/levels/LandscapeLevel.jsx` 的 `AI_TOOLS`，每一項的 `where` 欄位，
例如 `where: ["左側選單", "Artifacts"]`——改這裡就好。

# 前後端分工示意圖（第 2 關）

第 2 關「我做好了，怎麼給別人用？」最後一步的「換你分分看」，
上方會放一張示意圖，把六道題目畫成一張圖（左前端／右後端，中間資料往返）。

## 怎麼放

```
public/images/frontback-signup.jpg
```

- 檔名要**完全一致**（全小寫、用 `-` 不要用空白）。
- 橫式，建議 **1600×900 左右**；檔案大小盡量壓在 400 KB 以內。
- 圖上的 ① ~ ⑥ 和底部圖例，文字必須和 `src/levels/IntroLevel.jsx`
  的 `PARTS` **一字不差** —— 學生會把圖和下面的題目逐字對照：

  1. 講座公告的版面、文字和照片 —— 前端
  2. 把市民填好的報名資料存起來 —— 後端
  3. 報名額滿時，把按鈕變成灰色不能按 —— 前端
  4. 報名成功後，自動寄一封確認信給市民 —— 後端
  5. 決定哪些承辦同仁才能看到報名名冊 —— 後端
  6. 手機打開時，版面自動變成一欄 —— 前端

- 圖上**不要出現任何真實個資**（姓名、電話、email），表單欄位留空就好。
- 要換成別的副檔名，請一併改 `src/levels/IntroLevel.jsx` 裡
  `ZoomFigure` 的 `src`。

## 手機怎麼看

這張圖資訊密度高，縮到手機寬度會看不清楚，所以做成**點一下可以放大**
（`src/components/ZoomFigure.jsx`）。放大後在手機上是以原尺寸呈現、
可以左右滑動看細節；桌機則縮到整張看得完。按 Esc 或點背景關閉。

## 沒放會怎樣

整塊圖不會顯示，下面六道題目本來就是完整的教材，
不會出現破圖或空白區塊。
